# Joshua Seppich

I build AI agents and the integration layer that lets them operate real business software. I build them for Foxworks and the small businesses it serves.

Public repos:

- [bankbot](https://github.com/JoshTSeppich/bankbot): LLM discovers a legacy-UI workflow once; it becomes a typed, replayable capability that runs without the model.
- [Conductor](https://github.com/JoshTSeppich/Conductor): Runs several Claude Code sessions from one place: a tmux CLI, a local daemon, a web dashboard, and an Electron workstation with an orchestrator.
- [eventfold](https://github.com/JoshTSeppich/eventfold): EventFold is a desktop app I built to run B2B prospecting for Foxworks Studios end to end.
- [FindFold](https://github.com/JoshTSeppich/FindFold): FindFold is a command-line pipeline I built to find local service businesses that fit the FoxWorks.dev customer profile.

I build to production depth with AI-assisted tooling, keep a single linear main branch, and write down every design decision before the code.

Based in northern Utah. [foxworks.dev](https://foxworks.dev)
